Four-node LangGraph triage workflow (server/agent.py) Executed asynchronously in 2-worker background thread pool
1. context_node
Collects rule name, zone, mode, arming state, local clock, and last 5 SQLite event summaries.
Zero pixel data included.
→
2. decide_node (LLM)
Calls NVIDIA Cloud (nemotron-3-ultra-550b, 20s timeout). Parses JSON:
{"real": bool, "severity": str, "reason": str}
real=true →
real=false →
3a. notify_node
Persists anomaly + LLM reason to SQLite; triggers console border, beep & signed Hermes webhook.
3b. suppress_node
Logs anomaly in SQLite with [SUPPRESSED] prefix for auditability; skips phone push.
Policy: always_alert
Rules S1, S2, H8, H9, H18, P5, P9, P11, P13 force real = true; LLM cannot suppress.
Policy: review
Standard Home/Public detections; LLM evaluates context and may route to suppress_node.
Policy: log_only & Fail-Open
log_only rules (H4, H11, H17) bypass LLM; any LLM timeout routes to notify_node.
